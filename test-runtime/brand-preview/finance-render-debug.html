Finance Setup

WooCommerce already provides most of your sales data. Configure optional mappings only for additional costs recorded by your payment or affiliate plugins.

Available Automatically

  • Order Totals
  • Tax Breakdown
  • Payment Methods
  • Customer-Added Fees
  • Discounts
  • Shipping
  • Recorded Refunds

These fields use WooCommerce's existing order data and need no mapping. Reports still require financial data access and your account's WooCommerce permissions.

Payment Processing Fees & Affiliate Commissions

Processing fees are merchant costs. Customer-added fees are charges on the order and are already included automatically. A stored gateway net amount is not profit or a verified bank payout.

Choose a gateway to configure its exact order metadata keys, then test a known order before saving. No provider defaults are assumed. Affiliate systems using their own tables need a site adapter.

Advanced Mapping — Exact Metadata Keys

Enter metadata key names from your payment plugin's documentation or a known order. Do not enter amounts, API keys or credentials.

Payment Processing Fees

The scalar order metadata key containing the merchant processing fee.

Optional stored net amount; this is not calculated profit or a verified payout.

Optional three-letter currency metadata, such as MYR. Blank assumes the order currency for fee and net amounts.

Affiliate Details

Optional scalar order metadata identifying the referring affiliate.

Optional commission recorded on the order. A site affiliate adapter takes precedence over these affiliate fields.

Optional three-letter commission currency. Blank assumes the order currency unless a site adapter supplies its own value.

Test With an Order

Enter a known WooCommerce order's numeric ID. Only the requested finance fields are shown. This tests unsaved fields and does not save a mapping.

Saving a changed mapping invalidates unfinished change approvals.
